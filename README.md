# UserApp
Для запуска проекта необходимо запустить команду npm run dev
## Используемые библиотеки
Redux toolkit - управления состоянием \
Redux persist - кеширование данных \
React router - маршрутиазция \

## Оптимизация
Для оптимизации используются возможности React: React.lazy, suspense для ускорения первой загрузки и динамической подгрузки данных, не требующихся при первом рендере \
Кеширование данных с помощью redux persist и rtk query
